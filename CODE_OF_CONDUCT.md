# Code of Conduct

AzAdmin is an open-source project built through respectful technical collaboration.

## Expected behavior

Contributors and maintainers are expected to:

- Communicate respectfully and directly
- Critique code and decisions rather than people
- Give clear technical reasons for requested changes
- Respect different experience levels and backgrounds
- Credit contributors and external inspiration appropriately
- Avoid harassment, threats, discrimination, and personal attacks
- Keep project discussions focused on the work

## Unacceptable behavior

The following is not accepted in project spaces:

- Harassment or intimidation
- Discriminatory or demeaning language
- Publishing private information without permission
- Deliberate disruption of technical discussion
- Plagiarism or misrepresentation of authorship
- Repeated bad-faith behavior after a maintainer warning

## Enforcement

Maintainers may edit, hide, lock, or remove content and may temporarily or permanently restrict participation when necessary to protect the project and its contributors.

Report conduct problems privately to the repository owner or through an appropriate private GitHub channel. Reports will be reviewed as confidentially as reasonably possible.
