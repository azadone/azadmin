# Security Policy

## Supported versions

AzAdmin is currently in early development and has no stable supported release line yet. Security fixes are applied to the default development branch until a formal release policy is published.

## Reporting a vulnerability

Do not open a public issue for an exploitable vulnerability.

Use GitHub's private vulnerability reporting or a private security advisory for the repository. Include:

- Affected file or component
- Reproduction steps
- Expected and actual behavior
- Security impact
- Suggested mitigation, when available

Do not include real credentials, private user data, or destructive proof-of-concept payloads.

## Response process

The maintainer will review the report, confirm whether it affects AzAdmin, coordinate a fix, and publish an advisory when appropriate. Response time is not guaranteed during early development, but valid reports will be handled in good faith.
