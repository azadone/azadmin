# Documentation Workflow

Every meaningful step or commit includes an archive note under `docs/archive/`.

Each archive note records:

- Step number and date
- Status and objective
- Scope
- Architecture decisions
- Files created and modified
- Implementation notes
- JavaScript classification
- Accessibility, direction, theme, and responsive checks
- Automated check results
- Branch, commit, and pull request title
- Known limitations
- Previous and next steps

A separate Obsidian second-brain package uses `[[Wiki Links]]`, Parent/Previous/Next navigation, backlinks, and a project MOC. The repository documentation uses standard Markdown links so it remains navigable on GitHub.
