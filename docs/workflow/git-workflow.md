# Git Workflow

## Long-lived branches

- `main`: stable reviewed state
- `develop`: optional integration branch while the project is pre-release

## Working branches

```text
feature/*
fix/*
refactor/*
docs/*
chore/*
test/*
```

## Commit messages

Use Conventional Commits.

## Pull requests

Each pull request must remain focused, include the related archive note, pass project checks, and document responsive, RTL, theme, accessibility, HTMX, and WebAssembly considerations where relevant.
